# CommonParametersHelper

通用参数自动转换工具

设备软件升级时，新版本会附带一份新的通参模板。本工具将旧通参（设备当前配置，含传感器标定值与现场微调）自动迁移至新模板，输出可直接导入设备的 JSON 文件。

## 文档

**开发前请先阅读 [design.md](./design.md)**，其中包含完整的数据结构规格、匹配策略、取值决策规则与实现约束。

## 技术栈

- Python 3.10+
- PySide6（GUI）
- PyInstaller（打包为单 exe）

## 项目状态

设计阶段已完成，开发进行中。

## 开发顺序

核心逻辑与 UI 完全解耦，`core/` 目录不得引入任何 PySide6 依赖。请严格按以下顺序推进，每阶段通过验收后再进入下一阶段：

| 阶段 | 内容 | 验收标准 |
| --- | --- | --- |
| 1 | `loader.py` + 字节级往返测试 | 读入再写出，字节完全一致 |
| 2 | `loader.py` 结构校验 | design.md §2.3 四条不变量全部通过 |
| 3 | `validator.py` | 用 ValueRange 交叉验证表达式解析 |
| 4 | `matcher.py` | 同文件自匹配全部 Path 精确命中 |
| 5 | `policy.py` | P0–P4 各优先级用例通过 |
| 6 | `builder.py` | 补建节点字段正确，输出通过自检 |
| 7 | `cli.py` 端到端 | 同文件转换字节一致 |
| 8 | UI | — |

## 测试数据
